          Keyboard shortcuts
          
        
          
          
          ⌘O
          Open a paper folder
          
          
          ⌘P
          Go to file
          
          
          ⌘S
          Save and compile
          
          
          ⌘B
          Compile
          
          
          ⌘⇧R
          Reload files changed elsewhere
          
          
          ⌘J
          Show the cursor's line in the PDF
          
          
          ⌘-click
          Jump between the source and the PDF
          
          
          ⌘F
          Find in the file
          
          
          ⌘⇧E
          Switch between editing and suggesting
          
          
          ⌘⌥M
          Comment on the selection
          
          
          ⌘⌥K
          Ask Claude about the selection
          
          
          ⌃⌘S
          Show or hide the sidebar
          
          
          ⌘⇧M
          Show or hide Problems
          
          
          ⌘1 – ⌘8
          PDF, Suggestions, Checks, Outline, Review, Versions, Claims, Provenance
          
          
          ⌘?
          This list
          
          
          ⌘⇧P
          Export the PDF
          
        
          
        
          Opening, exporting, reviews and versions are in the menu bar.
